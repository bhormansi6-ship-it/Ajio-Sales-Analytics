# 🛍️ AJIO Sales Analytics

An Excel-based sales analytics project on AJIO e-commerce data, featuring pivot tables, charts, slicers and an interactive dashboard to uncover sales trends, category performance and revenue insights.

## 📌 Project Overview
This project analyzes **500 orders** from AJIO fashion e-commerce sales data to understand revenue, product performance, customer behavior and discount impact, helping drive data-driven business decisions.

## 📂 Workbook Structure
| Sheet | Description |
|-------|-------------|
| **Raw Data** | Original order-level dataset (500 records) |
| **Sheet1** | Cleaned data used for analysis |
| **KPI Dashboard** | Full-year performance summary with key metrics |
| **PIVOT TABLE** | Pivot tables and pivot chart data |
| **DASHBOARD** | Interactive dashboard with charts and slicers |

## 🗃️ Dataset Fields
Order ID, Order Month, Order Date, Project Name (campaign), Category, Brand, Region, Channel, Payment Mode, Gender, Units Sold, Unit Price (₹), Revenue (₹), Discount (%), Discount Amount (₹)

## 🔍 Key Analysis Areas
- Monthly and overall sales trends
- Revenue by category and brand
- Regional performance
- Sales by channel (App / Mobile Web, etc.)
- Payment mode distribution
- Gender-wise sales
- Campaign-wise performance
- Impact of discounts on revenue

## 🛠️ Tools & Techniques
- Microsoft Excel
- Data cleaning and formulas
- Pivot Tables and Pivot Charts
- Slicers for interactivity
- KPI Dashboard design

## 📁 How to Use
1. Download the `.xlsx` file from this repository.
2. Open it in Microsoft Excel.
3. Explore the **DASHBOARD** sheet and use the slicers to filter the data.
